# Fatima's Little World

موقع هدية عيد ميلاد تفاعلي لفاطمة، من أيمن. HTML / CSS / JS فقط، بدون مكتبات.

## المشاهد الخمسة
1. الاسم يتكوّن من آلاف الجزيئات المضيئة، تتفرق عند لمسها وتعود لمكانها
2. ذكريات: بطاقات زجاجية ثلاثية الأبعاد تميل مع اللمس (يمكن إضافة صور)
3. أمنيات: نجوم تربطها فيتشكل قلب، مع نغمات صوتية
4. الشمعة: تُطفأ بالنفخ في الميكروفون (أو بالضغط)، ثم ألعاب نارية ولحن عيد الميلاد
5. رسالة أخيرة تُكتب حرفًا حرفًا

## التعديل
كل النصوص في أول `script.js` داخل `CONFIG`. الصور تُوضع في `assets/` ويُكتب مسارها في `img`.

## النشر على GitHub Pages
1. ارفع كل الملفات إلى مستودع جديد (`index.html` في الجذر).
2. Settings ← Pages ← Source: `main` / `root` ← Save.
3. الرابط: `https://USERNAME.github.io/REPO/` (الميكروفون يحتاج https وهو متوفر على Pages).
